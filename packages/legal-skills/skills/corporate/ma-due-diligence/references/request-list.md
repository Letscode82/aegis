# Legal DD Request List (AEGIS standard)

Number requests by section so VDR folders and Q&A map one-to-one. Trim by deal type using the column codes:
**S** = share deal / scheme, **A** = asset or business transfer, **M** = minority investment, **J** = JV partner review.
Default look-back: 3 years (5 for tax, anti-bribery, environment). Materiality per the SKILL.md defaults unless the deal team sets one.

## Q&A discipline

- Each answer must reference a document or be confirmed in writing by management; oral answers are recorded as "management statement — to be warranted".
- After two rounds without response, convert to a finding (`gap`) with the assumed-adverse consequence.
